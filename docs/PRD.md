# 🧠 "어? hoxy ADHD인가?" - 나만의 ADHD 셀프체크 앱

## 🎪 프로젝트 소개
- **앱 이름**: "어? hoxy ADHD인가?" (Am I ADHD?)
- **컨셉**: 재미있고 부담없는 ADHD 셀프체크
- **만든이**: 호기심 많은 1인 개발자
- **목표**: 사람들이 자신을 더 잘 이해할 수 있도록! 🌟

---

## 🎯 왜 만들까?

### 💡 아이디어의 시작
"어? 나도 혹시 ADHD인가?" 하고 궁금해하는 사람들이 많아졌어요!
부담스럽게 병원 가기 전에, 커피 한 잔 마시는 시간에 가볍게 체크해볼 수 있으면 어떨까요?

### 🎈 우리의 철학
- **가볍게**: 무겁지 않게, 재미있게!
- **친근하게**: 의학용어 대신 일상 언어로
- **부담없이**: 무료로, 간단하게
- **도움되게**: 정확한 정보와 따뜻한 조언

### 🏆 성공했다고 할 수 있는 기준
- 사용자들이 "도움됐어!" 라고 말하면 성공 ✨
- 앱스토어에서 좋은 후기를 받으면 더 성공 🌈
- 많은 사람들이 자신을 이해하는데 도움이 되면 대성공! 🎉

---

## 🙋‍♀️ 누가 사용할까?

### 🎭 우리의 친구들

#### 🏢 직장인 민수씨
"회의 중에 딴 생각이 너무 많아... 혹시 나만 그런가?"
- **고민**: 업무 집중이 어려워서 야근이 늘어남
- **언제 사용**: 점심 먹고 나서, 집에서 쉴 때

#### 📚 대학생 지영이
"과제 미루다가 밤새는 일이 너무 많아졌어..."
- **고민**: 공부할 때 집중이 안 돼서 스트레스
- **언제 사용**: 시험 기간 전, 스트레스 받을 때

#### 👩‍💼 워킹맘 소현님
"애 돌보고 일하다 보니 깜빠먹는 일이 늘었어..."
- **고민**: 육아와 업무 스트레스로 건망증이 심해짐
- **언제 사용**: 아이 재울 때, 혼자만의 시간에

### 💭 이런 생각 해본 적 있나요?
- "나도 ADHD인가? 궁금하긴 한데..."
- "병원 가기엔 좀 부담스럽고..."
- "간단하게 체크해볼 방법 없을까?"
- "다른 사람들은 어떨까?"

## 🎮 앱에서 뭘 할 수 있을까?

### 🌟 메인 기능들

#### 📝 집중력 체크 테스트
"커피 한 잔 마시는 시간에 간단하게!"
- 18개의 재미있는 질문들
- "전혀 아니야 ~ 완전 맞아!" 4단계로 답하기
- 약 5분이면 끝!

#### 🎯 내 결과 보기
"나는 어떤 타입일까?"
- 점수와 함께 쉬운 설명
- "집중력 달팽이형", "활동적 다람쥐형" 같은 재미있는 표현
- 나만의 조언과 팁 제공

#### 📚 ADHD 알아보기
"ADHD가 뭔지 궁금해?"
- 쉬운 말로 설명하는 ADHD 정보
- 일상생활 꿀팁들
- 도움받을 수 있는 곳 안내

#### 📱 사용하기 편한 기능들
- 글씨 크기 조절 가능
- 테스트 중간에 잠깐 나가도 저장됨
- 친구들과 결과 공유하기 (개인정보 제외하고!)

### 🚀 나중에 추가하고 싶은 기능들

#### 📊 내 기록 보기
- 지난번과 이번 결과 비교
- "한 달 후에 다시 해보세요!" 알림

#### 💬 같이 이야기하기
- 익명으로 경험 나누기
- 궁금한 것들 질문하기

## 🛠 어떻게 만들까?

### 📱 어떤 폰에서 쓸 수 있을까?
- **안드로이드**: 조금 오래된 폰도 OK! (6.0 이상)
- **아이폰**: iPhone 6 이후 모델이면 다 가능!
- **개발 도구**: Flutter (한 번 만들면 둘 다 된다!)

### 🔧 사용할 기술들
```
앱 만들기: Flutter
데이터 저장: 내 폰에 안전하게 보관
광고: 구글 광고 (조금만!)
분석: 어떤 기능을 많이 쓰는지 알아보기
```

### ⚡ 빠르고 가볍게!
- **앱 켜는 시간**: 3초 안에 쌔빠르게
- **테스트 시간**: 5분이면 충분!
- **결과 보기**: 바로바로 2초 안에
- **앱 크기**: 50MB 이하로 가볍게

### 🔒 안전하게!
- **데이터 보호**: 아무도 못 보게 암호화
- **개인정보**: 정말 필요한 것만 최소한으로
- **투명성**: 뭘 어떻게 쓰는지 다 알려드리기

## 💰 어떻게 운영할까?

### 🎈 기본 철학
"일단 무료로, 부담 없게!"

#### 📱 완전 무료 앱!
- 모든 기능이 무료로 사용 가능
- 숨겨진 비용이나 구독료 없음
- 누구나 부담 없이 사용할 수 있도록

#### 🎯 운영비는 어떻게?
- 방해가 되지 않는 작은 광고로 운영비 충당
- 결과 화면 아래쪽에 작게 표시
- 사용자 경험을 해치지 않는 선에서만

#### 🤝 나중에 생각해볼 것들
- 정신건강 관련 유용한 서비스 소개
- 도움이 되는 앱이나 책 추천
- 하지만 절대 강요하지 않기!

## 📣 사람들에게 어떻게 알릴까?

### 🌱 천천히, 자연스럽게
"급하지 않게, 진짜 필요한 사람들에게만"

#### 🧪 먼저 친구들과 테스트
- 주변 친구들에게 먼저 써보라고 하기
- "이거 어때? 재미있지 않아?" 하며 피드백 받기
- 완전히 준비되면 앱스토어에 올리기

#### 📱 앱스토어에서 자연스럽게
- **제목**: "어? hoxy ADHD인가? - 가벼운 셀프체크"
- **설명**: 친근하고 부담 없는 톤으로 작성
- **스크린샷**: 실제 사용하는 모습들

#### 💬 입소문이 최고!
- SNS에 자연스럽게 소개
- 도움 받은 사람들이 직접 추천하도록
- 커뮤니티에서 정보 공유할 때 언급

## 🛡️ 안전하고 책임감 있게 만들기

### 💡 가장 중요한 것들

#### 🏥 의료진단은 아니에요!
"이 앱은 재미있는 셀프체크일 뿐이에요"
- 병원 진단을 대신할 수 없다는 것을 분명히 알려드리기
- 결과가 어떻든 궁금하면 전문가와 상담 권유하기
- "참고용"이라는 점을 계속 강조하기

#### 🔒 개인정보는 최소한만
"꼭 필요한 것만, 안전하게"
- 이름이나 전화번호 같은 건 절대 받지 않기
- 테스트 답변도 내 폰에만 저장하기
- 누군가 훔쳐볼 수 없도록 안전하게 보관하기

#### 📢 광고도 조심히
"도움이 되는 것만, 방해가 안 되게"
- 이상한 약이나 치료법 광고는 절대 안 하기
- 병원이나 의료 관련 광고는 정식 허가받은 곳만
- 사용자가 불편해하면 바로 개선하기

### 🤗 우리의 약속
"사용자를 최우선으로 생각하며, 정확하고 도움이 되는 정보만 제공하겠습니다!"

## 📅 언제쯤 만들어질까?

### 🏃‍♂️ 천천히, 단단하게
"급하게 만들면 좋지 않으니까!"

#### 1단계: 계획 세우기 (2주)
- [ ] 어떻게 만들지 더 자세히 계획하기
- [ ] 화면 디자인 그려보기
- [ ] 예쁘게 만들기 위한 준비

#### 2단계: 실제로 만들기 (4주)
- [ ] 앱 화면들 만들기
- [ ] 테스트 기능 만들기
- [ ] 결과 계산하는 부분 만들기
- [ ] 데이터 저장 기능 만들기

#### 3단계: 완성하고 테스트 (2주)
- [ ] 모든 기능 연결하기
- [ ] 친구들에게 써보라고 하기
- [ ] 문제점 고치기

#### 4단계: 세상에 공개! (1주)
- [ ] 앱스토어에 올리기
- [ ] 사람들에게 알리기
